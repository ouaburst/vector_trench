# Vector Trench — Rust source

This is the Rust port of the Pygame game. It uses Macroquad 0.4.16 and preserves the bending trench, flight controls, targets, fighters and laser bolts, scoring, hull damage, sound effects, and final reactor mission. The original WAV effects in `../assets/` are embedded in each Rust executable at build time.

Build and test from this directory with `cargo test` and `cargo build --release`. The project root README has platform-specific launch and cross-compilation instructions.
